# Business Intelligence Project

## Descripción

Este proyecto tiene como objetivo desarrollar paso a paso una solución de Business Intelligence utilizando SQL, Python y Power BI.

Durante el proyecto se construirá una base de datos, se realizará el proceso ETL, se crearán dashboards interactivos y se analizarán los datos para apoyar la toma de decisiones.

---

## Objetivos

- Aprender SQL.
- Diseñar una base de datos.
- Limpiar y transformar datos.
- Crear dashboards.
- Aplicar Business Intelligence en un caso real.

---

## Tecnologías

- Power BI
